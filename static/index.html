Tại sao nên kết nối Google Drive?
  • Lưu trữ save game không giới hạn trên Google Drive riêng của bạn (Zero backend cost).
  • Không bao giờ sợ mất file save khi cài lại Win, đổi máy hoặc lỡ tay xóa game.
  • Tự động khôi phục toàn bộ giờ chơi và thành tựu đã mở khi mở app trên PC mới.
Hướng dẫn 1 phút lấy Client ID Google Drive riêng:
  1. Bấm nút bên dưới để mở trang Google Cloud Console Credentials.
  2. Chọn Create Credentials > chọn OAuth client ID.
  3. Tại mục Application type, chọn Desktop app (Đặt tên: VietModHub).
  4. Copy mã Client ID (dạng ...apps.googleusercontent.com) dán vào ô bên dưới.
